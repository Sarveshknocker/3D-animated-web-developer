# Ready-to-paste prompts

Use these in any AI tool. With an agentic tool (Claude Code, Codex, Cursor, Copilot agent, Gemini CLI, Windsurf, Cline…) the kit files are read automatically after `init`. With a **chat-only AI** (ChatGPT, Gemini web, Claude.ai), first run `node bin/jarvis-immersive.mjs analyze <your-project>` and attach `.immersive/project-profile.md` plus the SKILL.md files mentioned below.

---

### 1. Full build (end to end)
```
Use the Jarvis Immersive kit (.immersive-kit/skills/immersive-build/SKILL.md).
Deep-dive this project and build the best original, interactive 3D/animated homepage for our brand,
natively in our stack, with all MNC quality gates. Work autonomously until every gate passes.
```

### 2. Review mode (you pick the concept)
```
Follow .immersive-kit/skills/immersive-creative-direction/SKILL.md.
Read .immersive/PROJECT_BRIEF.md (run the deep dive first if it's missing) and give me the top 3 concepts
with scores. Nothing template-like — each needs a user verb with a satisfying consequence.
```

### 3. Upgrade an existing section
```
Using the Jarvis Immersive kit, make the <section name> section on <page> feel premium and interactive.
Keep the content and copy; add motion/3D as progressive enhancement. Audit it when done.
```

### 4. Audit / harden
```
Run the Jarvis Immersive audit (.immersive-kit/skills/immersive-audit/SKILL.md) on this project.
Fix every FAIL, justify every WARN, and give me the before/after numbers.
```

### 5. Chat-only AI (no file access)
```
You are following the attached SKILL.md files (Jarvis Immersive kit). Attached is my project profile.
Step 1: ask me for the files listed in the deep-dive skill's Step 2 that you need.
Step 2: write the PROJECT_BRIEF. Step 3: propose concepts. Step 4: give me complete files to paste,
one at a time, native to my stack. Follow the MNC checklist for every file.
```
