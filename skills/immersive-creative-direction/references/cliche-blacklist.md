# Cliché blacklist

These are fine as *minor supporting details* but must **not** be the core concept. If a concept's pitch still works after replacing the brand name with a competitor's, it's a cliché.

## Visual clichés
- Iridescent / chrome floating blob in the hero
- Random low-poly geometric shapes slowly rotating
- Generic particle "galaxy" or starfield
- Purple→blue gradient mesh with no link to the brand palette
- Wireframe globe with arcs (unless the company genuinely is about global network data — and then make the data real)
- Glassmorphism cards floating over a blurred gradient
- Neon grid "synthwave" floor
- Abstract "AI brain" neural network lines
- Stock 3D laptop/phone mockup rotating
- Noise/grain overlay as the main effect

## Interaction clichés
- Scroll = everything fades up (as the *only* motion idea)
- Custom cursor circle that grows on links (as the *only* interaction)
- Text scramble/decode effect on every heading
- Horizontal scroll section "just because"
- Magnetic buttons everywhere
- Preloader with a percentage counter
- Parallax on every image

## Narrative clichés
- "The future is here" hero with a spinning object
- Timeline of company history as a vertical line with dots
- Logos marquee as the main proof point

## How to twist a cliché
Ask: *what would this be if it were made of the product itself?* Examples:
- Globe with arcs → for a logistics firm: a globe you can *spin to route a real parcel*, arcs are actual shipping lanes, cost updates live.
- Floating blob → for a skincare brand: the blob is the actual cream texture, you press it and it behaves like the real viscosity.
- Particle galaxy → for a developer tool: particles are real commits from the public repo, clustered by contributor.
