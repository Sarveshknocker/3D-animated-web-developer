# Cliché blacklist

These are fine as *minor supporting details* but must **not** be the core concept. If a concept's pitch still works after replacing the brand name with a competitor's, it's a cliché.

## Visual clichés
- Iridescent / chrome floating blob in the hero
- Random low-poly geometric shapes slowly rotating
- Generic particle "galaxy" or starfield
- Purple→blue gradient mesh with no link to the brand palette
- Wireframe globe with arcs (unless the company genuinely is about global network data — and then make the data real)
- Glassmorphism cards floating over a blurred gradient
- Neon grid "synthwave" floor
- Abstract "AI brain" neural network lines
- Stock 3D laptop/phone mockup rotating
- Noise/grain overlay as the main effect

## Interaction clichés
- Scroll = everything fades up (as the *only* motion idea)
- Custom cursor circle that grows on links (as the *only* interaction)
- Text scramble/decode effect on every heading
- Horizontal scroll section "just because"
- Magnetic buttons everywhere
- Preloader with a percentage counter
- Parallax on every image

## Narrative clichés
- "The future is here" hero with a spinning object
- Timeline of company history as a vertical line with dots
- Logos marquee as the main proof point

## How to twist a cliché
Ask: *what would this be if it were made of the product itself?* Examples:
- Globe with arcs → for a logistics firm: a globe you can *spin to route a real parcel*, arcs are actual shipping lanes, cost updates live.
- Floating blob → for a skincare brand: the blob is the actual cream texture, you press it and it behaves like the real viscosity.
- Particle galaxy → for a developer tool: particles are real commits from the public repo, clustered by contributor.

## Generated-site tells
AI-generated pages share a recognisable kit of parts. Each is harmless alone; together they read as "made by a model". None may carry the page, and every one you keep needs a reason tied to the brand.

| Tell | Instead |
|---|---|
| Pill badge or tiny uppercase label above the hero headline ("✦ New · AI-powered") | Put the information in the headline or the first sentence |
| Gradient text, or one word of the headline styled differently | One face, one colour; let the words carry the emphasis |
| Purple/indigo or cream-and-terracotta palette with no link to the brand | The brand's own colours, applied as large fields |
| Row of three identical icon-topped feature cards | A composition driven by the argument (claim → proof) |
| Glass panels and floating pill navigation over a blurred blob | A plain bar: wordmark, three to five links, one action |
| Soft drop shadows and glows on everything at rest | Tone steps between surfaces; shadows only on things that truly float |
| "Scroll to explore" with a bouncing mouse icon | A first screen that already shows the thing |
| Monospace captions, 01/02/03 index numbers, hairline grid lines as decoration | Hierarchy through size, position and words |
| Invented social proof (logo walls, "trusted by 10,000 teams", fake quotes) | Real proof or none; never fabricate |
| A 3D object that ignores the page (spins in a corner, unrelated to the copy) | The scene illustrates the claim next to it |
| Every section fading up the same way at the same speed | A motion system: one signature move, staggered entrances, feedback on controls |
| Emoji as icons, decorative blobs, fake dashboards of grey bars | A real picture, a real interface fragment, or nothing |
